## Our Products

### [EVA](https://eva.fyi) — Always one move ahead.
A private intelligence service for a single principal. It keeps the institution's memory, reads the world before it lands, and watches the relationships a leader depends on — the work reaches you each morning as one brief.
- Discreet. Intelligent. Sworn.
- Institutional memory, world awareness & relational intelligence, in one daily brief
- Principal-only, by request

### [nabh.cloud](https://nabh.cloud) — Every model under one sky.
India's prepaid LLM API marketplace. One API key, 18 open models — Llama, Mistral, Qwen and more — on OpenAI-compatible endpoints, billed in rupees.
- OpenAI-compatible API — swap the base URL, ship
- Pay via UPI, RuPay & net banking — no forex markup, no forced subscription, no international card required
- ₹50 free credit to start, prepaid balance never expires

### [AIDA](https://aida.ad) — Pipeline you trust. Outbound you approve.
AIDA spots buying signals the moment they surface, scores every lead, and drafts the outreach — nothing sends until you approve it.
- Detects signals live: LinkedIn hires, government tenders, alumni moves, event lists
- Explainable scoring across five weighted dimensions
- Approval-gated outreach across LinkedIn, email & WhatsApp — no cold blasts
- Built-in CRM tracks every lead new → qualified → contacted → won
